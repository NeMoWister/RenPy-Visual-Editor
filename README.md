## 🚀 Возможности

- 🎬 **Визуальное построение сценариев** из узлов (нод)
- 👤 **Управление персонажами** с цветовой маркировкой реплик
- 💬 **Диалоги, нарратор, меню выбора** с поддержкой `jump` / `call`
- 🖼 **Фоны, CG, спрайты** (включая составные из `sprites.rpy`)
- 🎵 **Музыка, звуки, эмбиенс** с настройкой fadein / fadeout
- 🏷 **Метки (`label`)**, переходы (`jump`), паузы, Python-код
- 👀 **Живой предпросмотр** сцены с перетаскиванием спрайтов
- 🧩 **Составные спрайты** - автоматический парсинг и наложение слоёв
- 📦 **Автоиндексация ресурсов** из папок `default/` и `custom/`
- 🏷️ **Теги и группировка** фонов/CG по категориям
- 🔍 **Поиск по нодам**, массовая замена текста, undo/redo
- 📺 **Режим презентации** - прогон сценария без экспорта в Ren'Py
- 📄 **Генерация `.rpy`**, экспорт `define`-блоков и ресурсов
- 🔄 **Импорт существующих `.rpy`** с сохранением нераспознанного кода
- 🌐 **Git-интеграция**, автосохранение, командная палитра

## 📥 Установка

### Готовая сборка

Скачайте последнюю версию в разделе **[Releases](../../releases)**.

После распаковки рядом с `.exe` должна находиться папка `resources/`:

```
RenPyVisualEditor/
├── RenPyVisualEditor.exe
├── resources/
│   ├── default/
│   └── custom/
├── characters.json
└── resources_config.json
```

### Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

## 📁 Структура ресурсов

```
resources/
    default/     ← ресурсы, уже объявленные в шаблоне игры (не попадают в define)
        bg/ cg/ sprites/ music/ sounds/
    custom/      ← ваши ресурсы (попадают в экспорт define/image)
        bg/ cg/ sprites/ music/ sounds/
```

> Подробнее о работе с ресурсами, тегах и составных спрайтах - в [Wiki](docs/WIKI.md).

## ⌨️ Быстрый старт

1. **Создайте проект:** `Файл → Новый проект` (Ctrl+N)
2. **Добавьте персонажей:** `Проект → Персонажи...` (Ctrl+P)
3. **Соберите сцену:** кнопка **«+ Добавить узел»** → выберите тип ноды
4. **Предпросмотр:** справа отображается текущее состояние сцены
5. **Экспорт:** `Генерация → Экспорт .rpy` (Ctrl+E)

## 🛠 Системные требования

- Windows 7/10/11 (для сборки `.exe`)
- Python 3.8+ (для запуска из исходников)
- Разрешение экрана: рекомендуется 1920×1080 и выше
