## 1. Быстрый старт 🚀

### Первый запуск

При первом запуске создайте новый проект через `Файл → Новый проект` (Ctrl+N).

![Интерфейс редактора](images/editor_main.png)

> 🖼️ *Скриншот: главное окно. Слева - список сцен и нод, в центре - редактор выбранной ноды, справа - окно предпросмотра.*

### Подготовка ресурсов

Создайте папку `resources/` рядом с исполняемым файлом:

```
resources/
  custom/
    bg/          ← фоны (.jpg, .png)
    cg/          ← CG-иллюстрации
    sprites/     ← спрайты (папки персонажей: sprites/us/normal/smile.png)
    music/       ← музыка (.ogg, .mp3)
    sounds/      ← звуковые эффекты
```

Ресурсы из `default/` работают в редакторе, но **не попадают** в экспорт `define`/`image` (предполагается, что они уже объявлены в базовом шаблоне игры).

### Типичная последовательность

1. **Метка (label)** - точка входа в главу
2. **Сцена (scene)** - показать фон, сбросить спрайты
3. **Музыка** - фоновый трек
4. **Показать спрайт** - вывести персонажа
5. **Диалог** - реплика

![Добавление узла](images/how_to_add_node.png)

> 🖼️ *Скриншот: выпадающий список выбора типа ноды при нажатии «+ Добавить узел».*

## 2. Общая структура 🗂️

- **Проект** состоит из **сцен**. Каждая сцена - это последовательность **нод** (узлов).
- **Нода** - одно действие: показать фон, сказать реплику, проиграть музыку и т.д.
- Слева - список сцен и нод текущей сцены.
- В центре - панель редактирования выбранной ноды.
- Справа - **живой предпросмотр**: фон, спрайты, текущая реплика.

## 3. Структура папки ресурсов 📦

### Два источника ресурсов

| Папка | Назначение | Попадает в экспорт define? |
|-------|-----------|---------------------------|
| `resources/default/` | Базовые ресурсы шаблона | ❌ Нет |
| `resources/custom/` | Ваши ресурсы | ✅ Да |

### Автоматические имена

| Категория | Пример файла | Автоимя |
|-----------|-------------|---------|
| Фон | `bg/bus_stop.jpg` | `bg bus_stop` |
| CG | `cg/d1_food_normal.jpg` | `cg d1_food_normal` |
| Спрайт | `sprites/us/normal/smile.png` | `us_normal_smile` |
| Музыка | `music/name.ogg` | `music_list["name"]` |
| Звук | `sounds/achievement.ogg` | `sfx_achievement` |

### Переопределение имён

`Проект → Настройки ресурсов → Переопределения имён`

- **Сохранить** - применить изменения
- **Экспорт / Импорт** - перенести набор имён между проектами
- **Сбросить** - удалить все переопределения (⚠️ безвозвратно)

![Настройки ресурсов](images/resources_settings.png)

> 🖼️ *Скриншот: окно настроек ресурсов с таблицей переопределения имён.*

## 4. Составные спрайты (sprites.rpy) 🧩

Если в `resources/*/sprites/` лежит файл **sprites.rpy**, редактор автоматически парсит `ConditionSwitch` и `im.Composite`, собирая спрайты из слоёв.

**Пример парсинга:**
```renpy
image cs normal stethoscope far = ConditionSwitch(
    "persistent.sprite_time=='sunset'", im.MatrixColor(im.Composite((630,1080),
        (0,0), "sprites/far/cs/cs_1_body.png",
        (0,0), "sprites/far/cs/cs_1_stethoscope.png",
        (0,0), "sprites/far/cs/cs_1_normal.png"), im.matrix.tint(0.94, 0.82, 1.0)),
    ...
)
```

**В редакторе:**
- Персонаж → Дальность (far / close / normal) → Эмоция
- В превью слои накладываются автоматически
- Условная раскраска (`im.matrix.tint`) игнорируется в превью

**Скрытие:** достаточно `hide cs`, а не полного имени.

![Выбор составного спрайта](images/select_sprite.png)

> 🖼️ *Скриншот: карусель выбора спрайта. Папки персонажей → дальность → эмоция с превью наложенных слоёв.*

## 5. Типы узлов 🎬

| Узел | Описание | Пример генерации |
|------|----------|------------------|
| **Диалог** | Реплика персонажа | `me "Текст"` |
| **Нарратор** | Текст без имени | `"Текст"` |
| **Сцена (scene)** | Фон + сброс спрайтов | `scene bg bus_stop` |
| **Фон (show)** | Фон без сброса спрайтов | `show bg bus_stop` |
| **CG** | Полноэкранная иллюстрация | `show cg d1_food_normal` |
| **Показать спрайт** | Спрайт с позицией и переходом | `show un smile at left with dissolve` |
| **Скрыть спрайт** | Скрыть конкретный или персонажа целиком | `hide un` |
| **Текстовое окно** | Управление окном диалога | `window show` / `window hide` |
| **Эффект (with)** | Отдельный переход | `with dissolve` |
| **Музыка** | Воспроизведение с fadein | `play music music_list["name"] fadein 2` |
| **Стоп музыка** | Остановка с fadeout | `stop music fadeout 3` |
| **Звук** | Звуковой эффект | `play sound sfx_achievement` |
| **Эмбиенс** | Фоновые звуки окружения | `play ambience ...` / `stop ambience` |
| **Метка (label)** | Точка входа | `label chapter_1:` |
| **Переход (jump)** | Переход к метке | `jump chapter_2` |
| **Меню выбора** | Меню с вариантами | `menu:` |
| **Пауза** | Ожидание клика или таймер | `pause` / `pause 2.0` |
| **Return** | Возврат из call | `return` |
| **Python код** | Произвольный код | `$ flag = True` |
| **Необработанный код** | RAW-блок (импорт из .rpy) | сохраняется дословно |

### Scene vs show

- **`scene`** - убирает **все** спрайты и CG перед показом фона. Используйте при смене локации.
- **`show`** - меняет только фон, персонажи остаются.

### Меню выбора

У каждого варианта:
- **Текст** - что видит игрок
- **Метка** - куда переходить
- **Галочка «call»** - по умолчанию `jump`, при включении - `call` (с возвратом после `return`)
- **Тело варианта** - inline-код Ren'Py, выполняемый при выборе

![Меню выбора](images/renpy_menu.png)

> 🖼️ *Скриншот: нода «Меню выбора» с тремя вариантами, полями для меток и галочкой call.*

### Переходы (transitions)

Встроенные: `dissolve`, `fade`, `fade2`, `fade3`, `flash`, `pixellate`, `blinds`, `squares`, `wipeleft`, `wiperight`, `wipeup`, `wipedown`, `vpunch`, `hpunch`, `dspr`.

Поле редактируемое: можно вписать собственный `define transform mytrans`.

**Группировка:** если несколько подряд идущих нод имеют одинаковый переход, при экспорте они объединяются в один общий `with` в конце группы.

## 6. Теги и группировка ресурсов 🏷️

`Проект → Теги ресурсов`

1. Создайте **категорию** (например, «Локация»)

## 7. Предпросмотр сцены 👀

Окно справа показывает состояние сцены на момент выбранной ноды:
- Фон / CG
- Все видимые спрайты
- Текущая реплика

**Интерактив:**
- **Перетащить спрайт** - изменить `xalign` (позицию по горизонтали)
- **Кликнуть по спрайту** - удалить ноду, которая его вывела
- **Наведение** - подсветка рамкой с подсказкой «удалить»

**Якоря по умолчанию:** `left`, `cleft`, `center`, `cright`, `right`, `fleft`, `fright`.

## 8. Персонажи 👤

`Проект → Персонажи...` (Ctrl+P)

- **Имя** - отображается в UI
- **Переменная** - то, что пишется в `.rpy` (`me`, `th`, `un`)
- **Цвет** - цвет имени в диалогах

**Кнопки:**
- Экспорт / Импорт списка в JSON
- Сбросить список

## 9. Импорт сценария `.rpy` (beta) 🔄

`Файл → Импорт сценария .rpy`

**Распознаётся:**
- `scene`, `show`, `hide` (фоны, CG, спрайты)
- `window show` / `window hide`
- `with` (в том числе общий для группы нод)
- Диалоги и нарратор
- `play music`, `stop music`, `play sound`, `play ambience`
- `label`, `jump`, `call`, `return`, `pause`
- `menu:` с вариантами и телами
- `$ ...` и блоки `python:`
- Условные блоки (`if`) - как RAW-ноды

**Что становится RAW:**
- `show X:` с ATL-блоком, если `X` не распознан
- `init python`, `transform`, `screen`
- Любые нераспознанные конструкции

## 12. Частые вопросы ❓

**Q: Добавил файлы в `resources/`, но их не видно.**
A: Нажмите F5 («Переиндексировать ресурсы») или перезапустите редактор.

**Q: В чём разница между «Сцена» и «Фон»?**
A: `scene` сбрасывает все спрайты, `show` - только меняет фон.

**Q: Составной спрайт не скрывается?**
A: Для составных спрайтов тегом является имя персонажа: `hide cs`, а не полное имя.

**Q: Категория тегов не отображается в ноде CG.**
A: Категории видны только там, где есть ресурсы с такими тегами. Назначьте тег хотя бы одному CG.

**Q: `show X:` с ATL превратился в RAW.**
A: Если `X` не найден в ресурсах, редактор сохраняет код дословно. Убедитесь, что файл лежит в правильной папке, и нажмите F5.

## 13. Как это работает: возможности по версиям 🧭

### v1.4.0

- **Меню выбора с вложенными нодами** - у варианта меню теперь может быть
  собственная встроенная цепочка нод прямо внутри него (не только переход
  на отдельную метку): сцена продолжается внутри варианта, а по её
  окончании редактор автоматически возвращается в общий поток сценария.
- **«Где используется»** - по любому ресурсу (фон, CG, спрайт, музыка,
  звук) можно посмотреть полный список мест использования по всему
  проекту, включая ноды, вписанные внутрь веток меню, с переходом к
  конкретной ноде.
- **Встроенный аудиоплеер с визуализацией волны** - в полях музыки/звука/
  эмбиенса рисуется waveform (через `ffmpeg`, если он есть в `PATH`), по
  которой удобно на глаз расставлять точки fadein/fadeout и перематывать
  плеер кликом по волне. Если `ffmpeg` не найден - сама волна не рисуется,
  но плеер и перемотка продолжают работать как обычно.
- **Режим презентации: запуск с любой ноды, перемотка, breadcrumbs** -
  прогон сценария можно начать не с самого начала, а с выбранной ноды
  (редактор довычисляет состояние сцены до неё); есть возврат к предыдущей
  реплике и хлебные крошки пройденных меток для навигации по нелинейному
  сценарию.
- **Проверка тайминга сценария** - оценка длительности прочтения по
  репликам/сценам/персонажам без реального прогона презентации. Обход идёт
  по `jump`/`label`, а не строго по порядку нод (иначе оценка была бы
  бессмысленной для нелинейных сценариев); чтобы не зависнуть на
  day-loop-подобных циклах, повторный проход одной метки ограничен, а при
  превышении лимита оценка помечается как неполная.
- **Построчный merge-помощник при экспорте** - если экспортируемый `.rpy`
  уже существует и в него вносили правки вручную мимо редактора, перед
  перезаписью показывается дифф. Отдельные несовпадающие куски (хунки)
  можно принимать (взять версию редактора) или отклонять (оставить как на
  диске) по одному, а не только «всё или ничего».
- **Многофайловый экспорт (по главам)** - сценарий можно разбить на
  несколько `.rpy`-файлов: один файл на сцену редактора, один на
  верхнеуровневый `label` (ближе всего к делению на главы/акты) или
  фиксированное число сцен на файл. Загруженные Ren'Py вместе, все файлы
  работают как один сценарий - `jump`/`call` между ними не ломаются.
- **Умный импорт (сопоставление существующих ресурсов)** - при импорте
  стороннего `.rpy` редактор распознаёт объявления вида
  `image bg beach = "bg/beach.png"`, `define audio.click = "sfx/click.ogg"`,
  `music_list = {...}` и подставляет уже знакомые имена вместо создания
  дублей.
- **Импорт персонажей с автоопределением цвета** - при импорте
  `Character("Алиса", color="#ff9966")` цвет реплик подхватывается прямо
  из объявления, перекрашивать вручную не нужно.
- **Проверка орфографии** - подсветка вероятных опечаток в репликах (для
  русского - через морфологический разбор pymorphy3, для английского -
  через словарь pyspellchecker) плюс технические проверки: незакрытые теги
  `{b}`/`{i}`/`{color}`, повторы слов, лишние пробелы и знаки препинания.
- **Командная палитра (Ctrl+Shift+P)** - быстрый поиск и запуск любого
  пункта меню редактора по названию, как в VSCode/Sublime. Список команд
  собирается автоматически из меню окна, отдельный реестр поддерживать не
  нужно - палитра не может разойтись с реальными пунктами меню.
- **Поддержка NVL / ADV режимов** - переключение между классическим ADV
  (реплика в окне снизу, без накопления) и NVL (реплики копятся столбиком
  на весь экран) - одинаково работает и в предпросмотре сцены, и в режиме
  презентации.

### v1.3.0

- **Сворачиваемые группы нод** - соседние ноды можно объединить в
  именованную цветную группу на графе сцены и сворачивать в одну строку,
  чтобы не листать длинную сцену целиком.
- **Копирование/вставка нод и цепочек** - копируется не только одна нода,
  но и последовательность подряд идущих нод целиком с сохранением порядка,
  вставить можно в другое место сцены или в другую сцену.
- **Поиск по нодам с переходом к результату** - поиск по тексту реплик и
  параметрам нод по всему проекту, с прыжком сразу к найденной ноде в
  нужной сцене.
- **Цветовая маркировка нод** - произвольным нодам можно назначить цветную
  метку для визуальной навигации по графу сцены (например, отметить
  ключевые сюжетные точки).
- **Undo/redo** - отмена и повтор построены на снапшотах состояния всего
  проекта, а не на патчах отдельных полей, поэтому одинаково надёжно
  работают для любых изменений - от правки текста до перестройки
  структуры сцен.
- **Счётчик реплик на персонажа** - статистика количества реплик, слов и
  символов на каждого персонажа (и отдельно - повествование без
  персонажа) для оценки баланса диалогов в сценарии.
- **Массовая замена текста** - поиск и замена текста сразу по всем
  репликам, вопросам и вариантам меню всего проекта (в отличие от точечной
  правки, доступной только при импорте `.rpy`), с предпросмотром совпадений
  перед заменой.
- **Избранное / недавно использованные ресурсы** - в карусели ресурсов
  файл можно отметить звёздочкой («избранное») для быстрого доступа, не
  роясь каждый раз по папкам.
- **Экспорт в текстовый формат и импорт правок** - сценарий выгружается в
  простой текстовый файл-«скринплей» (`Имя: Текст реплики` + скрытый
  служебный якорь на ноду) для вычитки сценаристом или редактором без
  самой программы; исправленный текст затем импортируется обратно и
  раскладывается по тем же нодам - структура сцен и типы нод при этом не
  трогаются.
- **Настраиваемые шаблоны нод** - можно завести собственный тип ноды
  (например, «Новая глава») со своими параметрами (строка/число/bool) и
  Jinja2-шаблоном генерации кода - в списке типов нод и на графе сцены она
  выглядит и ведёт себя как обычная встроенная.
- **Режим презентации (бета)** - первая версия прогона сценария без
  экспорта в Ren'Py, позже в v1.4.0 доработанная перемоткой и breadcrumbs.
- **Автосохранение и восстановление после краша** - состояние проекта
  периодически (раз в N секунд, если есть несохранённые изменения)
  целиком пишется в отдельный слот восстановления; если редактор закрылся
  аварийно, при следующем запуске предлагается восстановить несохранённые
  изменения.
- **Drag-n-drop ресурсов в карусель** - новые файлы можно перетащить прямо
  в окно карусели ресурсов вместо того, чтобы копировать их в папку
  `resources/` вручную и жать F5.
- **Версионирование проекта (снапшоты)** - тот же механизм undo/redo, но в
  виде отдельной панели истории: список последних действий с подписями, из
  которого можно одним кликом откатиться сразу до нужного шага, не нажимая
  Ctrl+Z много раз подряд.

### v1.2.0

- **Перекраска имён персонажей по настройкам** - цвет реплик персонажа
  меняется в одном месте централизованно, без правки каждой реплики по
  отдельности.
- **Обновлённый дизайн интерфейса** - визуальный рефреш без изменений в
  логике работы.

### v1.1.0

- **Подсказка длины реплики (200/340 символов)** - под полем текста
  показывается счётчик символов с мягкими ориентирами длины (стандартные
  пороги читаемости реплики на экране), чтобы текст не выходил за пределы
  диалогового окна в игре.
- **Воспроизведение музыки и звуков в редакторе** - выбранный трек или
  звук можно прослушать прямо в поле ноды, не запуская игру.
- **Теги для BG и CG** - ресурсы размечаются тегами и группируются по ним
  в карусели (см. раздел 6).
- **Импорт сценария `.rpy`** - первая версия импорта существующего
  Ren'Py-скрипта в проект редактора.
- **Ноды: scene, стоп музыки, window show/hide** - отдельные типы нод для
  этих действий (до этого набор типов нод был меньше).

### v1.0.0

- **Базовый визуальный редактор нод** - основа всего остального.
- **Поддержка спрайтов с подпапками (normal/far/close)** - структура папок
  персонажа по дальности плана.
- **Составные спрайты (`sprites.rpy`)** - распознавание `ConditionSwitch`/
  `im.Composite` (см. раздел 4).
- **Папки `default/` и `custom/`** - два источника ресурсов (см. раздел 3).
- **Автоматические имена ресурсов** - генерация имён по пути файла
  (см. раздел 3).
- **Живой предпросмотр сцены** - панель предпросмотра справа (см. раздел 7).
- **Управление переходами (dissolve, dspr и др.)** - набор встроенных
  transitions (см. раздел 5).
- **Меню выбора с jump/call** - базовый узел меню (см. раздел 5).
- **Руководство пользователя** - эта самая Wiki.
